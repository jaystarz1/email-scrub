    Help: what to check
    

    What is caught automatically: names in headers, greetings and sign-offs; emails; phones; dates; addresses; ID numbers; links; confidentiality notices.
    

    What is not reliably caught: single names in prose, nicknames, and context that identifies someone without naming them. Possible-name warnings cover some of this; read the full result.
    

    People versus Always remove: Me becomes <ME>. This thread and Saved people use an optional label or <PERSON-n>. Me is matched first; this-thread names take precedence over the same saved name forms. Always remove handles project names, organisations or any other identifying terms, one per line.
    

    The leak check: it checks whether details selected for removal still appear. Passing it is not proof of anonymity. “I checked: copy anyway” lets you copy despite a known match; review why it remains first.
    

    Preferences: only Me, Saved people, Always remove terms and highlighted exclusions are stored in this browser’s local storage and are not encrypted. This-thread people, threads, results and replacement maps are not saved. Saved people show only the date last used, updated when a name is actually replaced. Clear current thread removes its people but keeps Me and Saved people. Save moves a row into Saved people. Search ignores case and accents. Forget is disabled during the sample; leave the sample first. Use Forget saved people and exclusions to erase preferences. If this computer is shared, use Forget when you're done.
    

    Check it yourself: open the browser’s developer tools, go to the Network tab, run a scrub, and confirm nothing is sent.
    

    Using the AI’s reply: placeholders come back in the reply; swap the real names in before sending.
